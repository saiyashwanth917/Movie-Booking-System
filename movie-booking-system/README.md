# CineBook — Movie Ticket Booking System

Frontend-only movie ticket booking project using HTML, CSS and JavaScript.

## Movies
- Pushpa 2: The Rule
- Salaar: Part 1 – Ceasefire
- RRR
- They Call Him OG

## Features
- Uses the provided movie poster images
- Movie search and booking flow
- Date and showtime selection
- Interactive seat map
- Seat categories shown between rows: Regular ₹180, Premium ₹220, Recliner ₹300
- Booked/available/selected seat states
- Dynamic price calculation based on selected seat category
- Booking summary and digital ticket confirmation
- Responsive design
- localStorage used for passing booking information between pages

## Run in VS Code
1. Extract the ZIP.
2. Open the `movie-booking-system` folder in VS Code.
3. Install the **Live Server** extension.
4. Right-click `index.html` → **Open with Live Server**.
5. Click a movie → Book Now → choose showtime → choose seats.

No backend/database is required for this frontend demo.
